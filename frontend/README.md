# Frontend

React, TypeScript and Vite admin application.

From this directory:

```sh
npm install
npm run dev
```

Open http://localhost:4200. Start the backend separately from `../backend`;
Vite forwards `/api` and `/r` requests to http://127.0.0.1:8000.

Checks: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
